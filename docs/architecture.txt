================================================================================
                            关键数据流说明
================================================================================

1. 输入层
   - camFRONT.mpg 同时送入 VoiceModule（音频）和 TrackerModule（视频）
   - camBUP.mpg 和 camPOP.mpg 送入 BehaviorModule 做手指检测

2. 推理层（多进程并行）
   - VoiceModule:  Qwen3-ASR 语音转录，输出 key_moment
   - TrackerModule: 多目标跟踪、举手检测、距离/人数监控
   - GazeModule: 头部检测 + 凝视估计（在 Tracker 进程内运行）
   - BehaviorModule: 手指屏幕 + 手指文件检测

3. 双轨数据流
   - 事件流（绿色）：模块间业务通信，规则状态机消费
   - 推理流（橙色）：可视化数据，经 InferenceSync 对齐后推前端

4. 规则层
   - SupervisionRule:  监护制流程识别
   - InfoNoticeRule:   信息通报流程识别
   - SelfTicketRule:   自唱票流程识别
   - PersonnelStatusRule: 人员状态监控
   - FlowEventRecorder: 记录 flow_events.json

5. 评估层
   - 订阅 flow.started / flow.ended
   - 提取各模块 *_key_moments.json
   - Qwen3-8B 评估，输出 qwen_response_*.json

6. Web 层
   - FastAPI 接收 /start，设置 Redis 启动信号
   - WSHandler 通过 WebSocket 推送对齐后的 batch 到前端（二进制视频帧 + JSON 元数据）
